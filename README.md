# ฉลากอินซูลิน — Insulin Label Studio v2

เว็บแอปภาษาไทยสำหรับสร้างสติกเกอร์ความร้อน **1 มื้อ / 1 หน้า** เน้นตัวเลขขนาดยาและภาพกระบอกที่อ่านง่ายสำหรับผู้สูงอายุ

## สิ่งที่ปรับในเวอร์ชัน 2

- แยกเช้า เย็น ก่อนนอนเป็นคนละสติกเกอร์ เปิดมื้อกลางวันเพิ่มได้
- เลือกแนวตั้งหรือแนวนอน โดยสลับความกว้างและความสูงจริง ไม่หมุนเฉพาะภาพหน้าจอ
- เริ่มที่ 100 × 150 mm; แนวนอนเป็น 150 × 100 mm มีขนาด 100 × 100, 80 × 150, 58 × 180 mm และกำหนดเอง
- ตัวอักษรหลักเริ่มที่ 14 pt เลือกได้ 12, 14, 16 หรือ 18 pt ตัวเลขยูนิตและชื่อมื้อใหญ่กว่าข้อความทั่วไป
- ชื่อและ HN **ไม่บังคับ** ถ้าเว้นว่างจะไม่พิมพ์ช่องนั้น
- เลือกยา **NPH, MIXTARD, Regular** แยกตามมื้อ (U-100 เท่านั้น) ระบุเวลาเองตามใบสั่งยา ไม่มีการกำหนดเวลาให้อัตโนมัติเมื่อเลือกยา
- พิมพ์ทุกมื้อเป็นหลายหน้า หรือพิมพ์เฉพาะมื้อที่เลือก ส่งออก PNG ของมื้อที่กำลังดูได้
- แจ้งเตือนเนื้อหาเกินกระดาษและหยุดการส่งออก ไม่ย่ออักษรหรือแอบตัดคำแนะนำ

## อัปโหลดขึ้น GitHub

1. แตกไฟล์ `insulin-label-github-v2.zip` ก่อน
2. สร้าง repository หรือเปิด repository เดิม
3. เลือก **Add file → Upload files** อัปโหลดไฟล์ทั้งหมดที่แตกออกมาไว้หน้าแรก โดยให้ `index.html`, `style.css`, `label-core.js`, `app.js` อยู่ระดับเดียวกัน อย่าอัปโหลดเฉพาะ ZIP และอย่าซ้อนในโฟลเดอร์อีกชั้น
4. กด **Commit changes** บนสาขา `main`
5. ไปที่ **Settings → Pages → Build and deployment** เลือก **Deploy from a branch → main → /(root) → Save**
6. รอเผยแพร่ แล้วเปิด URL ที่ GitHub แสดงในหน้า Pages

ถ้ามีเว็บเดิมบน GitHub Pages แล้ว ให้อัปโหลดทับไฟล์เดิมและ **เพิ่ม `label-core.js` ด้วย** จากนั้นรีเฟรชหน้าเว็บ ถ้ายังเห็นรูปแบบเดิม ให้กด Ctrl+F5 (GitHub Pages แคชไฟล์ราว 10 นาที) เมื่อแก้ CSS/JS ครั้งต่อไป ให้เปลี่ยนเลข `?v=2.3` ใน `index.html` ด้วย เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่

ไฟล์ `.nojekyll` และ `.gitignore` ซ่อนอยู่บน macOS (กด Cmd+Shift+. เพื่อแสดง) แอปนี้ทำงานได้แม้ไม่ได้อัปโหลดสองไฟล์นี้ เพราะไม่มีไฟล์หรือโฟลเดอร์ที่ขึ้นต้นด้วย `_` และ repository สาธารณะจะเห็นซอร์สโค้ดได้ทุกคน แต่ไม่มีข้อมูลผู้ป่วยอยู่ในไฟล์

ไม่ต้อง build ไม่ต้องตั้ง API key หรือ GitHub Actions หากไม่พบเมนู Pages ให้ตรวจสิทธิ์และแผนบัญชีตาม[คู่มือ GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## วิธีใช้

1. กรอกชื่อและ HN เฉพาะเมื่อต้องการ
2. เปิดมื้อที่ใช้ เลือกยา ระบุขนาดยาและเวลาฉีดตามใบสั่ง
3. แท็บ **กระดาษ** เลือกขนาด แนวตั้ง/แนวนอน ระยะขอบ และขนาดอักษร
4. แท็บ **คำแนะนำ** เลือกเท่าที่จำเป็น ข้อความเหล่านี้จะพิมพ์ซ้ำทุกมื้อ
5. กดปุ่มมื้อเหนือภาพตัวอย่างเพื่อดูแต่ละหน้า ตรวจข้อมูล แล้วทำเครื่องหมายตรวจสอบใบสั่งยา
6. เลือก **ดาวน์โหลด PDF**, **พิมพ์ทั้งหมด**, **พิมพ์มื้อนี้** หรือ **PNG มื้อนี้** — ปุ่มพิมพ์จะสร้าง PDF ขนาดจริงแล้วเปิดในแท็บใหม่ ให้กดไอคอนเครื่องพิมพ์ในแท็บนั้น (ไม่เรียกหน้าต่างพิมพ์บนหน้าแอปโดยตรง เพราะ Chrome บน Windows อาจขึ้น Page Unresponsive ระหว่างรอไดรเวอร์เครื่องพิมพ์) — ปุ่มจะกดได้เมื่อไม่มีข้อผิดพลาดและติ๊กช่องตรวจสอบแล้ว ข้อความใต้ปุ่มบอกเหตุผลถ้ายังกดไม่ได้

ถ้าเปิดลิงก์จาก LINE / Facebook ปุ่มพิมพ์มักไม่ทำงาน แอปจะขึ้นแถบแดงให้กดเปิดใน Chrome / Safari
7. กด **ผู้ป่วยรายใหม่** ก่อนทำฉลากชุดถัดไป เพื่อล้างข้อมูลและคำแนะนำเฉพาะราย

ข้อมูลจากปุ่ม **เติมข้อมูลตัวอย่าง** เป็นข้อมูลสมมติและถูกกันการส่งออก เมื่อต้องการใช้งานจริงให้กด **ผู้ป่วยรายใหม่** แล้วกรอกข้อมูลตามใบสั่ง

## การตั้งเครื่องพิมพ์

เลือกขนาดกระดาษและแนวพิมพ์ในไดรเวอร์ให้ตรงกับแอป ตั้งสเกล **100%** ปิดหัว/ท้ายกระดาษและปิดการย่อให้พอดีหน้า ไฟล์จากปุ่ม **ดาวน์โหลด PDF** มีขนาดหน้าเท่าสติกเกอร์จริง เป็นภาพขาวดำตาม DPI ที่เลือก ให้สั่งพิมพ์แบบ **ขนาดจริง / Actual size** PNG มีจำนวนพิกเซลตาม 203/300 DPI ที่เลือก ให้กำหนดความกว้างและความสูงในแอปเครื่องพิมพ์ด้วย

ระบบกำหนดขนาดหน้าจริงและแบ่งหน้ามื้อละหน้าแล้ว แต่ไดรเวอร์/เบราว์เซอร์บางรุ่นอาจแทนที่ขนาดกระดาษ ต้องทดลองกับเครื่องพิมพ์จริงก่อนใช้ หากขึ้นเตือนเนื้อหาเกิน ให้เพิ่มขนาดสติกเกอร์ ลดคำแนะนำที่เลือก หรือปิดภาพขยาย การเลือกอักษรใหญ่มากหรือใส่ชื่อยาวอาจต้องใช้กระดาษใหญ่ขึ้น

## ขอบเขตการใช้และข้อมูล

รองรับกระบอกอินซูลิน **U-100 ขนาด 1 ml = 100 ยูนิต** รุ่นที่มีขีดใหญ่ทุก 10 ยูนิต ขีดสั้นทุก 2 ยูนิต ขนาดยาต้องเป็นเลขคู่ 2–100 ยูนิต ไม่ปัด ไม่แปลงความเข้มข้น และไม่คำนวณขนาดยาที่เหมาะสมให้ผู้ป่วย ภาพเป็นภาพประกอบ ไม่ใช่ขนาดกระบอกจริง ใช้ร่วมกับการสอนของทีมรักษา

ฟอร์มประมวลผลในหน่วยความจำของหน้าเว็บ ไม่มีการส่งข้อมูลผู้ป่วยไปเก็บบนเซิร์ฟเวอร์ และไม่มี localStorage ปิดหรือรีเฟรชหน้าจะล้างข้อมูล ไฟล์ PNG/PDF และงานพิมพ์มีข้อมูลที่ผู้ใช้กรอก ห้ามใส่ข้อมูลผู้ป่วยจริงไว้ในซอร์สโค้ดที่อัปโหลด GitHub

## เปิดในเครื่อง / ตรวจสอบโค้ด

ในชุด GitHub ดับเบิลคลิก `index.html` โดยเก็บไฟล์ CSS/JS ทุกไฟล์ในโฟลเดอร์เดียวกัน หรือใช้ไฟล์รวม `insulin-label-studio-v2.html` ที่ส่งให้แยกต่างหาก ในซอร์สสำหรับ Sites ไฟล์หน้าเว็บอยู่ใน `dist/`

หากติดตั้ง Node.js ให้เปิด terminal ในโฟลเดอร์ชุดไฟล์แล้วรัน `node verify.cjs` ทดสอบขนาดยา สเกล ตำแหน่งลูกสูบ การไม่บังคับชื่อ/HN การแยกมื้อทั้งสองแนว การเกินกระดาษ และการแสดงข้อความอย่างปลอดภัย

คำแนะนำพื้นฐานอ้างอิง [MedlinePlus](https://medlineplus.gov/ency/patientinstructions/000660.htm) และ [CDC](https://www.cdc.gov/diabetes/treatment/treatment-low-blood-sugar-hypoglycemia.html) ตรวจแหล่งข้อมูลวันที่ 12 พฤศจิกายน 2569
